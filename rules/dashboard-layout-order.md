# Dashboard order: questions, then percentages, then activity

Date: 2026-11-12

Rule: The dashboard shows open questions first and only when there are any, then the per-app percentage tiles, then what changed and what is in flight. A question the owner answered leaves his view once handled.

Incident: The owner reads on a phone and had to scroll past status lists and re-read questions he had already answered.

Why: The tiles are the first thing he looks at.

How to apply: When an answer arrives, clear the flag and record the decision in the same turn. Layout may change freely; a counting rule changes only with the owner's agreement.
